Connect Firefox to Pawprint Tagger

In the Pawprint Tagger project folder, run the updated desktop build once to register its Firefox bridge:

./artifacts/PawprintTagger/PawprintTagger --install-firefox-bridge

Use “Check desktop connection” in the extension popup to confirm the connection.

Add an image

Open an individual Danbooru or Gelbooru post. Click “Add to Pawprint Tagger” below its original-image or download link, or use the extension toolbar button.

Firefox downloads the original to its Downloads/PawprintTagger folder with your current session and container cookies. Pawprint Tagger copies it into the open library; if the app is closed, it uses your saved library folder. Existing images receive missing tags without being copied again. Tags keep their booru names and are grouped under Booru → site → category. A unique matching tag already in your library is reused.

Original images and imported tags are saved together. The original checksum is verified when the post supplies one. A missing original, inaccessible post, or video is reported; a sample is never substituted.

Retry an import

If a file finished downloading but the desktop import failed, keep the download and use “Retry import” in the popup after resolving the error. You do not need to download it again.

Installation

This development build can be loaded from about:debugging#/runtime/this-firefox → “Load Temporary Add-on” → select the extension’s manifest.json or XPI file. Firefox removes temporary add-ons when it closes. Permanent installation in regular Firefox requires a Mozilla-signed build.

The desktop bridge installer supports Linux desktop Firefox. Sandboxed Firefox packages may need their own native-messaging integration. Re-run the registration command after moving the published application.

Privacy

Images and tags are sent to your local Pawprint Tagger app. The extension contacts only the booru you are viewing and its image servers; there is no remote Pawprint service or telemetry. The cookies permission selects the correct Firefox container for the download; cookies are not sent to Pawprint Tagger. Recent private-window imports stay in memory, while images you explicitly add are saved in your library.
